# İlaç Hatırlatıcı

Offline Android medication reminder app. This repository currently contains the Phase 01 Expo foundation only; medication records and reminders are not implemented yet.

## Development

```bash
npm install
npx expo start --go
```

The shell can be viewed in Expo Go. Native notification work will require a development build:

```bash
npx expo run:android
```

`eas.json` also contains development and Android APK preview build profiles for later use.
